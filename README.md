# Retail Banking Transaction Analysis Using SQL

## Project Overview

This project focuses on analyzing retail banking data using MySQL.

The bank manages customers, accounts, branches, loans, loan payments,
cards and financial transactions.

The main goal of this project is to analyze banking data and generate
useful business insights related to customer behavior, account activity,
transactions, loans and card usage.

## Tools Used

- MySQL
- SQL
- GitHub

## Dataset

The project contains 7 related tables:

1. Customers - 500 records
2. Accounts - 700 records
3. Branches - 40 records
4. Loans - 300 records
5. Loan Payments - 2,000 records
6. Cards - 600 records
7. Transactions - 5,000 records

## Database Structure

The database is designed as a relational database using primary keys
and foreign keys to establish relationships between tables.

Main relationships:

Customers → Accounts → Transactions

Customers → Accounts → Cards

Customers → Loans → Loan Payments

Branches → Accounts

Branches → Loans

## Business Objectives

### 1. Customer Profile & Segmentation

Analyze customer demographics, income, credit scores, KYC status
and customer segments.

### 2. Account Usage & Branch Activity

Analyze account balances, account types, account activity and
branch performance.

### 3. Transaction Patterns

Analyze transaction types, channels, transaction amounts and
customer transaction behavior.

### 4. Loan Performance & Repayment

Analyze loan types, principal amounts, outstanding balances,
loan status and repayment patterns.

### 5. Card Usage & Product Engagement

Analyze card types, credit limits, outstanding balances,
reward points and customer engagement.

## Key Analysis

The project includes SQL analysis to identify:

- Customer segments with higher customer counts
- Customers with higher credit scores
- Branches with higher account balances
- Transaction types with higher transaction amounts
- Highly active customers and accounts
- Loan types with higher lending exposure
- Branches with higher outstanding loan balances
- Card types with higher credit limits and reward points

## Business Insights

The analysis helps understand customer behavior, account activity,
transaction patterns, loan exposure and card engagement.

These insights can support customer targeting, account management,
transaction monitoring, loan risk management and card service
improvements.
